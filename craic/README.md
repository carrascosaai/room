# Craic · Practica inglés hablando con una IA

App web (PWA) para practicar conversación en inglés con un personaje nativo.
El modelo de lenguaje se ejecuta **dentro de tu navegador** con WebGPU
([WebLLM](https://github.com/mlc-ai/web-llm)): sin servidor, sin API keys, sin cuentas.

> README completo en construcción (Fase 4).

```bash
cd craic
npm install
npm run dev      # http://localhost:5173  (añade ?demo para probar sin GPU)
npm test
```
