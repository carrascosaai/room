# Proyecto de Ingeniería de Materiales: el hormigón armado

- `Memoria_Hormigon_Armado.docx`: memoria editable (unas 24 páginas).
- `Memoria_Hormigon_Armado.pdf`: la misma memoria en PDF.
- `generar_memoria.js`: script que genera el .docx (`npm install docx && node generar_memoria.js`).
- `figuras/generar_figuras.py`: genera las figuras (`pip install matplotlib && python3 figuras/generar_figuras.py`).

Antes de entregar: rellenar la portada (autores, profesor, universidad) y, en Word,
actualizar el índice (clic derecho → «Actualizar campos»).
